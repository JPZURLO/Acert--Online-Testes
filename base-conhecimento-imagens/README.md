# Pacote de Imagens da Base de Conhecimento (Online Teste)

Este pacote foi gerado de forma 100% automatizada utilizando **Selenium Headless Chrome** no ambiente local.

## Como Executar Novamente a Captura:
```bash
python scripts/generate_knowledge_base_screenshots.py
```

## Estrutura do Pacote:
- `site-publico/`: Capturas das páginas institucionais públicas.
- `empresa/`: Capturas dos módulos do painel da empresa.
- `participante/`: Capturas do ambiente do candidato.
- `artigos/`: Imagens separadas por slug de artigo.
- `mapa-imagens-base-conhecimento.md`: Mapeamento detalhado.
- `manifesto-imagens.json`: Manifesto de importação em JSON.
- `onde-colocar-as-imagens.md`: Guia de integração HTML.
